Editor de Word online gratis

Utilizá el editor de Word online de UtilMooz para crear y modificar documentos desde cualquier dispositivo. No necesitás instalar Microsoft Word para realizar las funciones básicas de edición.

Abrir archivos DOCX

Podés cargar documentos DOCX existentes y editar su contenido directamente desde el navegador.

Crear documentos Word

También podés crear un documento nuevo desde cero, agregar texto, títulos, listas, imágenes y diferentes formatos.

¿Dónde se procesa el documento?

Las funciones principales se realizan directamente en el navegador. El archivo seleccionado no necesita ser enviado a un servidor propio de UtilMooz.
